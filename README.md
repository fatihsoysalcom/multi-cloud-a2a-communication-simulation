# Multi-Cloud A2A Communication Simulation

This example simulates Application-to-Application (A2A) communication across different cloud environments (AWS, Azure, GCP). It demonstrates how services conceptually residing in separate clouds can interact by passing messages through shared queues. An AWS inventory service initiates an order, an Azure payment service processes it, and a GCP analytics service logs the outcome.

## Language

`python`

## How to Run

Save the code as `main.py`.
Run from your terminal: `python main.py`
